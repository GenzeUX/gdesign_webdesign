G. DESIGN — запуск сайта

1. Откройте папку проекта, склонированного из GitHub или распакованного из архива.
2. Установите LTS-версию Node.js, если она ещё не установлена.
3. Дважды щёлкните START.cmd.
4. Дождитесь Ready и откройте адрес из окна запуска, обычно http://localhost:3000.

Окно должно оставаться открытым. Остановка — Ctrl+C.
При занятом порте Next.js напишет другой адрес.

В PowerShell используйте npm.cmd вместо npm:
npm.cmd ci
npm.cmd run dev

Конфигурация формы хранится в .env.local. Пример — .env.example.
Не публикуйте файл .env.local и секретные токены.
Подробная инструкция и настройки Vercel находятся в README.md.
